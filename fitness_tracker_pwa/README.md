# FORM Tracker — iPhone Home Screen App

## Publish free with GitHub Pages

1. Sign in at https://github.com and create a new **Public** repository called `fitness-tracker` (do not include personal check-in data in the repo).
2. Download and unzip `fitness_tracker_pwa.zip` on your computer.
3. In the repository click **Add file → Upload files**, and upload the **contents** of the `fitness_tracker_pwa` folder (all six files, with `index.html` at the root). Commit.
4. In **Settings → Pages**, select **Deploy from a branch**, branch **main**, folder **/(root)** and **Save**.
5. Once published, go to `https://YOUR-GITHUB-USERNAME.github.io/fitness-tracker/` in **Safari on your iPhone**.
6. Tap **Share → Add to Home Screen → Add** (the wording may show **Open as Web App** on newer iOS versions).
7. Launch **FORM Tracker** from your Home Screen.

## Privacy and backups

- Your check-ins are kept **only in local browser storage on that device and web app origin**, not in GitHub or synced automatically to your other devices.
- Use **Data & goals → Export data (.json)** regularly. Save to iCloud Drive. Import it to restore or transfer devices.
- If you delete website data, uninstall the Home Screen app, or change the hosted URL, stored information may be lost.
- The app shell can load offline after its initial visit; backups and app installation still require appropriate browser/device support.
- Update the site later by uploading replacement files to the same repository. Changes may need an app refresh to become visible.
